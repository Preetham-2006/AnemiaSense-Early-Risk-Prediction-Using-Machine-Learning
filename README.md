# AnemiaSense-Early-Risk-Prediction-Using-Machine-Learning
AnemiaSense is a machine learning-based healthcare application designed to predict the risk of anemia using Complete Blood Count (CBC) parameters such as Hemoglobin, RBC, WBC, MCV, MCH, MCHC, RDW, and Platelet count. It uses the LightGBM algorithm to analyze blood parameters and provide anemia risk predictions along with health insights.
